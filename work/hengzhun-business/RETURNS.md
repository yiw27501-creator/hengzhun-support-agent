# 已签收退货演练

工作台点击“新增已签收退货工单”，选择新工单。

客服提出方案 → 客户接受 → 创建唯一退货单 → 客户提交模拟物流 → 仓库签收 → 仓库验收 → 后台退款 → 回执核验。

客户拒绝方案回到客服；物流异常可由客服重新查询；验收不通过转争议处理，申请重新验收后才能继续。客服确认不能绕过仓库验收。步骤版本冲突、跳步、重复验收退款请求均拒绝。退款沿用原引擎和唯一执行回执。

本机所有角色按钮仅为演练入口，没有多角色鉴权；物流、验收、退货资格、运费政策均为合成样例。没有真实承运商回调、自由文本协商、真实仓库检查、真实支付到账或客户消息发送。已完成状态仅表示沙箱退款回执已核验。存在人工协助的退货不会计为自动办结。

验证：86 项自动化测试通过，新增测试覆盖完整退货、提前退款拦截、版本冲突、物流异常恢复、验收争议与重新验收。数据库持久化记录退货单、模拟物流单号及每一步事件。
